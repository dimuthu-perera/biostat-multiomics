# Synthetic example library

All files in this directory are completely synthetic and are not derived from real participants. They are designed to demonstrate supported matrix structures, declarations, statistical behavior, and guardrails; they are not claimed to reproduce the full biological distribution of any assay.

`catalog.json` powers the browser Load Example workflow. `truth.json` documents a small set of planted relationships. Regenerate the library with `python scripts/generate_synthetic_examples.py`.
